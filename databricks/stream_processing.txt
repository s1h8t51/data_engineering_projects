spark.readStream
1️⃣ Kafka Topic

From Apache Kafka:

df = spark.readStream.format("kafka") \
    .option("kafka.bootstrap.servers", "host:9092") \
    .option("subscribe", "topic_name") \
    .load()
2️⃣ Event Stream (Cloud Managed Kafka)

Azure Event Hubs example:

df = spark.readStream.format("eventhubs") \
    .options(**event_hub_config) \
    .load()
3️⃣ IoT Sensor Data

Usually via:

Kafka
MQTT
Event Hubs
Kinesis

Spark reads from those connectors.

4️⃣ Live Application Logs

Example (monitor folder continuously):

df = spark.readStream \
    .format("json") \
    .load("/logs/incoming/")

Spark keeps watching folder for new files.

🔥 How Does It “Continue to Follow”?

Streaming uses:

Micro-batching
Checkpointing
Offset tracking

Example:

query = df.writeStream \
    .format("delta") \
    .option("checkpointLocation", "/mnt/checkpoints/") \
    .start("/mnt/output/")

Checkpoint ensures:

No data loss
Exactly-once processing
Resume after failure
