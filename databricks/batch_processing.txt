-- quarentine implementation 
raw_df = spark.read \
    .format("csv") \
    .option("header", "true") \
    .option("mode", "PERMISSIVE") \
    .load("path")
valid_df = raw_df.filter("delay_minutes >= 0")
invalid_df = raw_df.filter("delay_minutes < 0 OR delay_minutes IS NULL")
valid_df.write.format("delta").mode("append").save("/mnt/bronze/train_valid")
invalid_df.write.format("delta").mode("append").save("/mnt/quarantine/train_invalid")

--  Parquet File (S3)
df = spark.read.parquet("s3://bucket/path/")

Parquet is preferred in production (columnar + optimized).

-- Table in Database (JDBC)
df = spark.read.format("jdbc") \
    .option("url", "jdbc:postgresql://host:5432/db") \
    .option("dbtable", "schema.table_name") \
    .option("user", "username") \
    .option("password", "password") \
    .load()

Spark connects via JDBC driver.
